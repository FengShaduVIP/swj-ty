# 天一 BMS 通讯协议说明（Modbus-RTU）

> 本文档由 `modbus协议寄存器映射表V7-4G专用V1.xlsx`（V7-4G 专用 V1）整理而成，供上位机 / 调试工具开发参考。
> 协议本质：**标准 Modbus-RTU**（非 JBD 私有帧）。文档本身存在若干错漏，已在第 11 节列出，实现时**以设备实测为准**。
> 范围：本文档覆盖 A000–AA01 全部可读写寄存器与复位/控制指令；OTA 固件升级（第 10 节）仅作记录，v1 不实现。

---

## 1. 物理层与帧格式

- 物理通道：USB 串口（与 JBD 共用同一路串口，按所选协议切换）。
- 默认串口参数：**9600 / 8 数据位 / 1 停止位 / 无校验（None）**，从机地址默认 `0x01`（A505/A506 可配 1–255）。
- 标准 Modbus-RTU 帧：

```
[从机地址 1B] [功能码 1B] [数据 N 字节] [CRC 低 1B] [CRC 高 1B]
```

- **校验**：标准 Modbus **CRC16**（多项式 0x8005，初始 0xFFFF，低字节在前）。
- **功能码**：
  - `0x03` 读保持寄存器
  - `0x04` 读输入寄存器（时间戳实时上报用）
  - `0x06` 写单个寄存器
  - `0x10` 写多个寄存器（用户信息、复位/控制、OTA 用）
  - 异常响应 = `0x80 | 原功能码`，后续 1 字节为异常码（01 非法功能 / 02 非法地址 / 03 非法数据 / 06 忙）。

---

## 2. 地址基准

- 文档中的「A000」等即为 **Modbus 保持寄存器地址 `0xA000`**（十进制 40960），**下发使用 0 基准，无 40001 偏移**。
- 验证依据（文档读指令样本）：`01 03 a0 00 00 2f` = 从机 01 / 功能 03 / 起始地址 `0xA000` / 数量 `0x2F`(47)。
- 寄存器分区总览：

| 地址段 | 内容 | 典型读指令（从机 01） |
|---|---|---|
| 0xA000–0xA0FF | 电池信息（packinfo） | `01 03 a0 00 00 2f` |
| 0xA100–0xA1FF | 单体电压 | `01 03 a1 00 00 18`（按串数，示例 24） |
| 0xA300–0xA3FF | 单体温度 | `01 03 a3 00 00 04`（按温度数，示例 4） |
| 0xA400–0xA4FF | 设备信息 / 用户与版本（User_Info） | `01 03 a4 00 00 10` |
| 0xA500–0xA5FF | 电池基础配置 | `01 03 a5 00 00 1c` |
| 0xA600–0xA6FF | 保护参数配置 | `01 03 a6 00 00 4c` |
| 0xA700–0xA7FF | 校准参数配置 | `01 03 a7 00 00 35` |
| 0xA800–0xA8FF | 休眠配置 | `01 03 a8 00 00 19` |
| 0xA900–0xA9FF | 复位 / 控制 | 按钮触发（写 `0x0001`），无需读 |
| 0xAA00–0xAAFF | 实时 / 历史上报时间戳 | `AA00` 读用 `0x04`，写用 `0x10` |

---

## 3. 数值换算与字节序

- 每个寄存器为 **U16 无符号整数**，大端（高字节在前）。
- 最终显示值：`Value = (上报值 − 偏移量 offset) × 分辨率 gain`。浮点显示保留 1 位小数。
- **32 位值**：由两个连续 U16 拼接，小端方式 —— **首寄存器为低字**，即 `Value = Reg[N] + Reg[N+1] × 65536`。
- 字符串寄存器（用户名 / 密码 / IMEI / IMSI / CCID / 版本串）：HEX 上报，按 ASCII / UTF-8 解析（文档对"UTF8 / UTF16"表述前后不一致，见第 11 节，需设备实测）。

---

## 4. 通讯时序规则（必读）

1. 任意两条请求指令之间须 **≥500 ms 间隔**，且上一条已响应回传，方可发下一条；否则到达 500 ms 后重复发送本条。
2. **3 秒内无回传 → 上位机报通讯故障**（循环弹出/消失，恢复后报"通讯恢复"）。
3. 周期轮询顺序（1.5 s 循环）：
   `电池信息 → 500ms → 单体电压 → 500ms → 单体温度/阻抗/日志 → 500ms →（1.5s 更新）→ 电池信息 …`
   客户更关注电池信息与单体电压，故优先高频。
4. 版本信息、用户信息寄存器 **初始化读一次**即可，修改名称等之后再读一次。
5. 切换到配置 / 高级界面时，停止首页轮询；配置界面只读刷新一次（修改过的项修改后需再读一次）。

## 7. 设备信息 / 用户与版本（0xA400–0xA4FF，初始化读一次）

- 典型读：`01 03 a4 00 00 10`（16 个寄存器）。
- 均为字符串寄存器，HEX 上报、ASCII/UTF-8 解析，一般不可修改（除用户名/密码）。
- 结构：
  - `NAME1–NAME16`（A400–A40F）：用户名，可修改，UTF-8，写不足补空格。
  - `pwd1–pwd8`（A410–A417）：密码，可修改，默认不显示。
  - `imei1–imei8`（A418–A41F）、`imsi1–imsi8`（A420–A427）、`ccid1–ccid10`（A428–A431）：不可修改。
  - `ec_sw1–ec_sw8`（A432–A439）、`ec_hw1–ec_hw8`（A43A–A441）：不可修改（软件/硬件版本串）。
  - `bms_sw1–bms_sw8`（A442–A449）、`bms_hw1–bms_hw8`（A44A–A451）：不可修改。

> ⚠ 文档对用户名/密码的编码表述前后不一致（一处"utf16 解析"、多处"UTF8 解析"），且 4G 版本串解析方式需设备实测确认（见 11.5）。

### 8.2 Alarm1 / Alarm2（A028 / A029，每 bit 为 0–3 等级，0 无 / 1 轻 / 2 普通 / 3 严重）

- Alarm1（bit 0,2,4,6,8,10,12,14）：电压断线 / 温度断线 / MOS温度高 / 压差保护 / 短路保护 / 放电过流2 / 放电过流1 / 单体欠压。

- 告警只提示不参与策略动作；保护位 0/1 会改变状态。

| bit | 0–3 | 4 | 5 | 6 | 7 | 8 | 9 | 10 | 11–15 |

## 10. 复位 / 控制指令 与 时间戳（0xA900–0xAAFF）

- **复位 / 控制**（按钮触发，写 `0x0001`，功能码 `0x10`）：

| HEX | 变量 | 名称 | 触发 |
|---|---|---|---|
| A900 | RESET | 系统重启 | 写 0x0001 |
| A901 | RECONVERY_BMS | BMS 恢复出厂（全部配置格式化后重启） | 写 0x0001 |
| A901 | RECONVERY_EC | 4G 模块恢复出厂 | 写 0x0001（⚠ 与 BMS 恢复出厂同地址，区分方式见 11.6） |

- **时间戳**（AA00 实时上报时间 / AA01 历史上报时间）：
  - `AA00`：读用 `0x04`（实时页周期 3 秒读，若 10 s 内无更新则停止实时上报）；写用 `0x10`，范围 1–100 s。
  - `AA01`：历史上报时间，写范围 10–65535 s。
  - ⚠ 下发前需输入 `~!@#$%^&*` 比对（防止非专业人员误操作导致系统崩溃）。

### 10.1 OTA 固件升级（记录，v1 不实现）

- 采用 Modbus `0x10` 功能码，固件拆 128 字节/包传输。
- 握手：`0xF000` 写包数 → 成功回 `01 10 F0 00 00 01`；失败回 `01 90 03`；超时（200 ms 无响应）重握手，连续 100 次失败中止。
- 数据传输：`0xF001` 起每包 128 字节，地址累加；失败要求重传。
- 结束跳转：`0xFEAA` 写 `00 01`（仅升级）/ `00 02`（擦除保护+基础配置后升级）/ `00 03`（擦除全部后升级），即复位 MCU。

## 12. 上位机实现提示（供调试工具参考）

- 连接验证：发 `01 03 a0 00 00 01`（读 A000 电芯数量）确认通讯；成功即获取 `CellNum`/`TempNum` 决定后续读取长度。
- 建议提供"通用寄存器读写"调试区（读保持寄存器 X 数量 Y / 写单寄存器 X=V），便于现场核对上述文档错漏。
- 轮询严格遵循第 4 节时序；bus 串行队列 + 单条在途可自然满足 ≥500 ms 间隔与 3 s 故障判定。
- 字符串寄存器写入走 `0x10` 多寄存器；注意 UTF-8 编码与长度/补空格规则（见 11.5）。
